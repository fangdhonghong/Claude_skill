# Logic Whetstone (逻辑磨刀石) 🔪

> **Sharpen your technical decisions through structured friction.**

## 💡 项目理念

在复杂的系统设计与技术选型中，最危险的不是“不知道”，而是“以为自己知道”。

**Logic Whetstone** 并非一个只会点头称赞的 AI 助手。它是一块坚硬的、冷酷的逻辑磨刀石。它的核心存在意义是**通过质疑来消除模糊性**。它会不断对你的方案进行极限施压，逼迫你暴露隐性假设，直到你的决策逻辑在边界条件下依然坚不可摧。

## 🎯 核心能力

### 1. 深度决策树拆解
它不会泛泛而谈。当你输入一个方案，它首先会将其拆解为一颗“决策树”，识别出所有底层的关键节点与依赖关系。

### 2. 节点级压力测试
**一次只磨一个点。** 它会强迫你停留在当前决策节点，针对该节点的 Trade-offs（权衡）和 Edge Cases（边界场景）进行反复论证。在逻辑闭环前，它会拒绝跳转到下一个话题。

### 3. 拒绝“顺从性”陷阱
它被设计为严禁说出“这个想法很好”这类无意义的赞美。它唯一的任务是寻找漏洞。

### 4. 动态对冲建议
它不替你做决定，但当你面对风险点无法自圆其说时，它会提供业界成熟的“对冲方案（Hedging Strategies）”供你参考，辅助你完善决策。

## 🚀 使用流程

1. **提交方案**：向 Logic Whetstone 描述你的初步决策（如：架构调整、技术选型、重大变更）。
2. **审计节点**：AI 会指出决策树中的第一个关键分歧点，并向你发起挑战。
3. **逻辑论证**：你需要解释你的理由、你所做的权衡以及你打算如何处理极端情况。
4. **推进或深挖**：
   - 如果论证有漏洞，AI 会继续在该节点深挖。
   - 如果论证逻辑闭环，AI 会给出该环节的避坑指南，并推进到决策树的下一个分支。
5. **获得成品**：当所有节点“研磨”完毕，你将获得一个具备极高可落地性的坚韧方案。

## ⚠️ 适用场景

- **架构审计**：对现有方案的健壮性进行评估。
- **技术选型**：在多个竞争方案之间寻找逻辑支撑。
- **防呆设计**：在方案上线前，预判可能出现的故障模式。
- **思维训练**：提升决策者对系统依赖和边界风险的敏感度。
